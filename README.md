# 拉斯维加斯 / 凤凰城片区站点数据看板

单页静态看板,打开链接即可查看。与北加看板无任何共享文件或数据。

```
index.html                    看板本体(单文件,含全部数据,约 2.4 MB)
data/price_adjustments.csv    价格表 — 改这个文件即可调价
build/                        重新生成看板的源文件与脚本
README.md
```

`index.html` 里 2.0 MB 是 890 个未开邮编的边界数据。之所以仍然内联而不外挂成单独文件,是为了保住「双击本地文件也能完整使用」这一点 —— 浏览器禁止 `file://` 页面 fetch 本地 JSON。GitHub Pages 会自动 gzip,实际传输约 700 KB。

## 部署(GitHub Pages)

仓库根目录即站点根目录。在 GitHub 上:**Settings → Pages → Source: Deploy from a branch → Branch: main, folder: / (root) → Save**,约一分钟后链接生效。

链接稳定不变,后续更新数据只需提交,Pages 会自动重新部署。

## 六个视图

侧边栏「按以下维度着色」可切换:

- **站点** — 每个邮编归属哪个站点
- **DSP** — 每个邮编的承运商。**DSP 代号已剥离站点前缀**(`PHX-ECS` → `ECS`),所以同一家 DSP 跨站运营时会合并统计。ECS 横跨 PHX01/TUC01/CGZ01/FLG01 四站,XAE 横跨 IFP01/PRC01 两站
- **线路** — 单站点内按线路着色,右侧面板可点选单条线路高亮;放大到 8 级以上会在地图上显示线路编号
- **价格** — 首票价格 0-1lb 的深浅分布
- **单量** — 日均单量的深浅分布
- **难易度** — 邮编难易度 A/B/C/D 级。**仅 LAS01、TUC01 两站有评级数据**,覆盖 85/241 个邮编,未评级的邮编显示为深蓝灰

灰色的**未开邮编**在六个视图下都在,不随视图切换,因为「哪里没开」是每个视图都要对照的底。

难易度视图能看出定价逻辑:难度越高,熟手 PPH 越低、单价越高。

## 未开邮编

亚利桑那、内华达、犹他三州里**没有任何站点覆盖**的邮编,共 **890 个**,在地图上统一画成灰色,自成一类。六个视图下都显示,侧边栏「未开邮编」开关可以整层关掉。

以前地图上那些空白处看不出是「没开」还是「数据缺了」,现在一目了然 —— 比如拉斯维加斯市中心那块缺口,就是 89109(拉斯维加斯大道)、89119(机场)、89169(会展区)、89191(内利斯空军基地)这一串未开邮编。

点开任意一个灰色邮编,会显示城市、州、以及**离它最近的站点和直线距离**,用来判断值不值得延伸覆盖。

|---|---|
| `85043` 已开通邮编 | 飞到该邮编,弹出站点 / DSP / 线路 / 单量 / 价格 |

## 可分享的深链

```

#view=routes&station=LAS01      看 LAS01 的线路分布

```

## 底图说明

默认使用 **Esri 彩色街道图**,左下角「底图」按钮可切换 5 种:

| 底图 | 说明 |
|---|---|
| 彩色街道图 | 默认,米色底 + 路网 + 城市名,风格接近北加看板 |
| 彩色地形图 | 带地形起伏,适合看郊区线路 |
| 深色 Dark | 与侧边栏同色系,邮编色块对比度最高 |
| 卫星影像 | 看实际场地和路网 |
| OSM 标准 | 需通过 http(s) 访问才可用,见下 |

之所以不把 OSM 设为默认:**openstreetmap.org 会拒绝不带 `Referer` 请求头的瓦片请求**,返回一张写着「Access blocked」的提示图。而浏览器从 `file://` 打开页面时不发送 Referer,所以双击本地文件打开时整张地图都会变成封锁提示图。Esri 没有这个限制,因此部署后和本地直接打开都正常。

> 北加看板用的是 OSM 瓦片,同样存在这个问题 —— 本地双击打开会看到封锁提示图,通过 http 访问则正常。

## 本地直接打开 vs 部署后

双击 `index.html` 用 `file://` 打开时:

- 地图正常(Esri 底图不受影响;切到「OSM 标准」则会显示封锁提示图)
- **调价表不会被读取** —— 浏览器安全策略禁止 `file://` 页面读取本地 CSV,此时显示内置基准价格,侧边栏会给出琥珀色提示

部署到 GitHub Pages 或任何 http 服务后两者都正常。本地想完整预览可以起一个临时服务器:

```bash
cd las-phx-console
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

## 调价流程

`data/price_adjustments.csv` 有 241 行(`zip,price`),是当前的全量基准价。

1. 用 Excel 改价格,保持 CSV 格式
2. 提交到仓库
3. GitHub Pages 约 1 分钟后重新部署,所有人打开链接就是新价格

页面加载时会读取这个 CSV 并**重算全部派生指标** —— 邮编价 → 线路价(按单量加权)→ 站点均价 → DSP 均价,地图配色和排行榜同步更新。侧边栏「价格表」会显示读取了多少个邮编、其中多少个与内置基准价不同。

注意:直接用 `file://` 打开本地文件时,浏览器安全策略会阻止读取 CSV,此时页面使用内置基准价。部署到 GitHub Pages 后一切正常。

## 数据来源与口径

- **价格** — `GOFO WE DSP对应关系 （高链）.xlsx`,取**首票价格 0-1lb**。LAS、PHX 用财务版报价表。STG 的源表里叠了三个版本的报价,取报价生效日期最新的那版(2026-07-27,$2.05)
- **日均单量** — 各站点运单明细,按邮编聚合。每个导出文件视为该站一天的量;PRC01 例外,它的导出跨了两个有实质量的日子,只取完整的 04/09
- **FLG01 的 4 个邮编** — 单量按领导指定值填入(140/140/110/20),未使用运单统计值
- **难易度 / 熟手 PPH** — 源表的「邮编难易度」「熟手PPH（件）50%」两列,只有 LAS 和 TUC 的报价表有
- **邮编边界** — US Census 2020 ZCTA5,服务端简化至约 100 米精度。邮编 `84771`、`84791`、`85288` 无 ZCTA 边界(PO Box 专用邮编),地图上不绘制色块,坐标取所属站点服务区的单量加权中心
- **站点坐标** — Census Geocoder 对 8 个站点地址精确匹配
- **未开邮编** — 两个来源合并,缺一不可:Census ZCTA5 提供边界(但无人区和 PO Box 专用邮编没有 ZCTA),GeoNames 美国邮编库提供城市名和全部邮编的坐标点。未开邮编与已开通邮编用**同一个简化精度**拉取,否则两层交界处会出现肉眼可见的缝隙
- **三州邮编范围** — 按邮编前缀划定,这三个州的前缀是干净不重叠的:UT `84xxx`,AZ `85xxx`/`86xxx`,NV `889xx`/`89xxx`

## 重新生成看板

改完数据后:

```bash
cd build
python build_mapdata.py     # 从 Excel 重新生成 mapdata.json + price_adjustments.csv
python assemble.py          # 组装出 ../index.html
```

只有在邮编清单发生变化(新增/删除邮编)时才需要重新拉取地图边界:

```bash
python fetch_geo.py         # 已开通邮编的边界 + 站点地理编码
python fetch_unopened.py    # 未开邮编(约 5 分钟,658 个多边形分 17 批拉取)
```

两个脚本都需要联网。**开通了新邮编之后,两个都要重跑** —— 否则新邮编会同时出现在「已开通」和「未开邮编」两层里。`fetch_unopened.py` 是按 `mapdata.json` 里的已开通清单做差集的,所以顺序是:先 `build_mapdata.py`,再 `fetch_unopened.py`,最后 `assemble.py`。

`build/` 各文件职责:

| 文件 | 作用 |
|---|---|
| `assemble.py` | 把下面各部分拼成单文件 `index.html` |
| `build_mapdata.py` | 读 Excel + 难易度,生成 `mapdata.json` 和价格 CSV |
| `fetch_geo.py` | 拉取已开通邮编的边界和站点/邮编坐标 |
| `fetch_unopened.py` | 拉取 AZ/NV/UT 全部未开通邮编的边界和城市名 |
| `lasphx_app.js` | 看板全部交互逻辑 |
| `lasphx_body.html` | 侧边栏与地图区的 HTML 骨架 |
| `base.css` | 深色控制台设计系统(从北加看板 fork 一次后独立维护) |
| `lasphx_extra.css` | 本片区特有样式(六个视图标签、站点跳转、难度图例) |
| `mapdata.json` | 站点/线路/DSP/邮编全部数据 |
| `zipgeo.json` | 238 个已开通邮编的边界多边形 |
| `unopened.json` | 890 个未开邮编:边界、城市名、坐标(2.0 MB,占页面体积的大头) |
| `geo_aux.json` | 邮编中心点、站点坐标、无边界邮编清单 |
